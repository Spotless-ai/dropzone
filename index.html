      Privacy and supported files

      The selected files are processed in memory on this device. There is no upload endpoint, account system, analytics, external font or CDN script. Loading the app still makes ordinary requests to GitHub Pages. No offline caching is included.

      Image conversion redraws the picture and does not copy original EXIF, GPS, IPTC or XMP metadata. This is not a guarantee of anonymity: visible information stays in the picture, and encoders can add their own technical metadata. Animated images, SVG, GIF, HEIC and RAW formats are not supported.

      Limits: 100 files, 100 MB total input, 25 MB per image, 24 megapixels per image, and 100 MB of generated outputs. Your browser may run out of memory below these limits. Cancel stops the processing worker; closing or reloading clears the selection and outputs.

      This is the browser edition. Video conversion, ZIP extraction and PDF editing are not included. Image tools require a browser with worker, OffscreenCanvas and createImageBitmap support. Browser compatibility testing is ongoing; if a format cannot be encoded, the app reports an error instead of silently substituting another format.
